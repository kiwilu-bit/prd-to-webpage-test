# PRD to Webpage Test

## 这是什么项目

探索一种 AI 驱动的极简前端交付工作流：直接将产品 PRD 作为输入，结合前端组件库和设计规范 Skills，由 AI 自动生成可交付的页面原型。

## 预期结果

通过两组对照实验，验证设计 Skills 对 AI 生成页面质量的提升效果：

- **1.0 版本（测试组）**：PRD → 前端组件库 → 生成页面
- **2.0 版本（对比组）**：PRD → 设计 Skills → 更新后的前端组件库 → 生成页面
